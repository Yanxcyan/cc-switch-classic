# CC Switch Classic v4.0.25

A small interface polish release.

- The Direct / Routing / Aggregation mode switcher above the provider list now has vertical spacing, so its tabs no longer touch the bar edges.
- Usage detail tabs use a clearer track and the selected tab now lines up with the others; counts on the selected tab use a lighter badge for readability.
- Other pages using the same tabs (such as Skills and the memory panel) share the updated track color.

## Updating

Installed Classic builds can check for updates in About. Windows portable users download the new ZIP and replace the program after exiting. First-time Classic users install manually from this repository's Releases page; upstream builds do not migrate automatically.

macOS builds use ad-hoc signing and are not notarized by Apple. First launch may require approval in System Settings → Privacy & Security.
