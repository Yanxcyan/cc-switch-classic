# CC Switch Classic v4.0.23

Classic 的首个独立发布版本，以 CC Switch v4.0.22 为业务基线。

- 恢复经典界面，并保留 v4 的模式、账号、代理和用量统计功能。
- 设置六个页签统一使用宽版布局；关于页与更新日志链接指向 Classic 仓库。
- 安装包使用独立名称、应用标识和更新签名，更新只来自 `Yanxcyan/cc-switch-classic`。
- 提供 Windows x64/ARM64 安装版及便携版、macOS 通用版、Linux x64/ARM64 安装包。

## 首次安装与更新

请从本仓库 Releases 手动安装首个 Classic 安装包；原作者版本的更新器不会迁移到 Classic。后续安装版可在“关于”中检查 Classic 更新，Windows 便携版下载新版压缩包后退出应用再替换程序。

macOS 未配置 Apple Developer 证书时使用 ad-hoc 签名，未经 Apple 公证，首次打开可能需要在“系统设置 → 隐私与安全性”中允许。

Classic 沿用当前用户的 `.cc-switch` 数据与客户端配置，也保留 `ccswitch://` 链接兼容性。安装标识独立不代表数据隔离；首次使用前请备份现有配置，不要同时运行两个版本。
