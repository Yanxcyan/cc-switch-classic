# CC Switch Classic v4.0.26

同步上游 v4.0.23–v4.0.25 的业务更新，继续保留 Classic 经典界面、页签间距、供应商目录策略和已有配置兼容性。

## 新增与改进

- MCP 支持按需检查 stdio、HTTP 和 SSE 连接。
- 新增可选的 Codex 官方配额保护，默认关闭；启用后可在五小时或每周配额耗尽前暂停经本地路由发送的官方请求。支持设置子代理并发上限。
- 用量页面支持自动汇率，默认仍为手动设置。
- Kimi、MiniMax 和 Oh My Pi 支持原生配置编辑；登录流程支持设置是否自动打开浏览器及复制登录链接。
- 完善推理强度兼容性、模型说明和供应商预设，支持删除 Kimi 会话。

## 修复

- 本地代理拒绝来自网页的请求及异常主机名，增强浏览器来源和 DNS 重绑定防护。
- 修复 Codex/Pi 用量重复统计、导入问题及代理环境下模型价格同步失败。
- 修复 Windows 表单闪动、启动时托盘响应、轻量模式和终端继承路由设置等问题。
- 保留历史预设位置与旧域名识别，避免已有供应商配置错配；继续沿用 Classic 的展示和推广链接策略。

## 更新方式

已安装 Classic 的用户可在“关于”中检查更新；Windows 便携版下载新版压缩包后退出应用再替换程序。首次使用 Classic 请从本仓库 Releases 手动安装，原作者版本不会自动迁移。

macOS 版本使用 ad-hoc 签名，未经 Apple 公证，首次打开可能需要在“系统设置 → 隐私与安全性”中允许。
