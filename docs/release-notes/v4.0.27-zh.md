# CC Switch Classic v4.0.27

本版同步上游 v4.0.26 至 v4.0.36 的业务更新。已有供应商预设保留原有位置。

## 主要变化

- 在经典顶栏切换 GitHub Copilot CLI 和 WorkBuddy，管理供应商及会话。
- 从供应商页的「更多」菜单管理插件，技能仓库支持使用令牌访问私有仓库。
- 代理设置新增出口 IP 检测，可为经路由的供应商设置费用倍率。
- 修复 Codex 路由兼容性、OpenCode 旧版会话用量导入及部分模型计价问题。
- 在通用设置中调整界面密度与缩放。

## 更新方式

已安装 Classic 的用户可在「关于」中检查更新。Windows 便携版请下载新版 ZIP，退出程序后替换文件。macOS 安装包使用 ad-hoc 签名，首次打开时可能需要在系统的「隐私与安全性」设置中允许。
