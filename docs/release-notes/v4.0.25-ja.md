# CC Switch Classic v4.0.25

画面の細部を整えた修正リリースです。

- プロバイダー一覧上部の直接接続 / ルーティング / 集約の切り替えバーに上下の余白を追加し、タブが枠に接しないようにしました。
- 使用統計の詳細タブの背景を見やすくし、選択中のタブを他のタブと同じ高さに揃えました。選択中タブの件数は明るいバッジで表示します。
- 同じタブを使う他の画面（スキル、メモリパネルなど）も背景色を統一しました。

## 更新方法

インストール済みの Classic は「情報」から更新を確認できます。Windows ポータブル版は新しい ZIP をダウンロードし、終了後にプログラムを置き換えてください。初めて Classic を使う場合は本リポジトリの Releases から手動でインストールしてください。上流版からは自動移行しません。

macOS 版は ad-hoc 署名で、Apple の公証はありません。初回起動には「システム設定 → プライバシーとセキュリティ」で許可が必要な場合があります。
