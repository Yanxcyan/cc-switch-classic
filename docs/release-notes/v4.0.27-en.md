# CC Switch Classic v4.0.27

This Classic release incorporates upstream application changes from v4.0.26 through v4.0.36. Existing provider presets keep their original positions.

## Highlights

- Switch to GitHub Copilot CLI or WorkBuddy in the Classic header to manage providers and sessions.
- Manage plugins from the provider page’s More menu and access private skill repositories with a token.
- Check the outbound IP in proxy settings and set cost multipliers for routed providers.
- Improve Codex routing compatibility, usage imports from older OpenCode sessions, and model pricing.
- Adjust interface density and zoom in General settings.

## Updating

Check for updates in About. For Windows portable installations, download the new ZIP, quit the app and replace the files. The macOS build uses ad-hoc signing and may require approval in Privacy & Security on first launch.
