# CC Switch Classic v4.0.26

上流 v4.0.23–v4.0.25 の機能更新を取り込み、Classic の画面、タブの余白、プロバイダ表示方針、既存設定との互換性を維持しました。

## 追加・改善

- stdio・HTTP・SSE の MCP 接続を必要に応じて確認できます。
- Codex 公式クォータ保護を追加しました。初期状態は無効で、有効にすると5時間または週間の上限に達する前にローカルルーター経由の公式リクエストを一時停止できます。サブエージェントの同時実行数も設定できます。
- 使用統計で自動為替レートに対応しました。初期設定は引き続き手動です。
- Kimi、MiniMax、Oh My Pi のネイティブ設定編集、ログイン時のブラウザ自動起動設定、ログインリンクのコピーに対応しました。
- 推論レベルの互換性、モデル説明、プロバイダプリセットを改善し、Kimi セッションの削除に対応しました。

## 修正

- ローカルプロキシがウェブページからの要求と不正なホスト名を拒否し、ブラウザ経由の要求と DNS リバインディングへの保護を強化しました。
- Codex/Pi の使用量の重複、取り込みの問題、プロキシ環境でのモデル料金同期を修正しました。
- Windows のフォームのちらつき、起動時のトレイ応答、軽量モード、ターミナルへのルーティング設定の継承を修正しました。
- 既存プリセットの位置と旧エンドポイントの識別を維持し、Classic の表示方針とプロモーションリンク方針を保持しました。

## 更新方法

Classic をインストール済みの場合は「バージョン情報」から更新できます。Windows ポータブル版は新しい ZIP をダウンロードし、終了後にプログラムを置き換えてください。初回は本リポジトリの Releases から手動でインストールしてください。上流版から自動移行はされません。

macOS 版は ad-hoc 署名で、Apple の公証は受けていません。初回起動時は「システム設定 → プライバシーとセキュリティ」で許可が必要な場合があります。
