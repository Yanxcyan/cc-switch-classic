# CC Switch Classic v4.0.24

The first independent Classic release, based on CC Switch v4.0.22.

- Restores the Classic interface while retaining v4 modes, accounts, proxy and usage features.
- Uses a consistent wide layout across all six settings tabs. Project and changelog links open the Classic repository.
- Uses a separate product name, application identity and updater signing key. Updates come from `Yanxcyan/cc-switch-classic`.
- Packages Windows x64/ARM64 installers and portable ZIPs, a universal macOS app, and Linux x64/ARM64 packages.
- Simplifies the provider picker to PackyCode, first-party providers and major platforms such as Qiniu. Saved providers remain available for editing and use.
- Hides other sponsor API-key promotions and points PackyCode to https://www.packyapi.ai/register?aff=VGGr.

Install this first Classic release manually from this repository's Releases page. The upstream updater does not migrate to Classic. Later installers can check for Classic updates in About; Windows portable users download the new ZIP and replace the program after exiting.

Without Apple Developer credentials, macOS builds use ad-hoc signing and are not notarized. First launch may require approval in System Settings → Privacy & Security.

Classic shares the current user's `.cc-switch` data and client configuration and retains `ccswitch://` compatibility. Separate installer identities do not isolate data. Back up existing configuration before first use and avoid running both editions together.
