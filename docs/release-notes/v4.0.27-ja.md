# CC Switch Classic v4.0.27

上流の v4.0.26 から v4.0.36 までの変更を取り込みました。既存のプロバイダープリセットは従来の位置を維持します。

## 主な変更

- Classic のヘッダーから GitHub Copilot CLI と WorkBuddy のプロバイダーやセッションを管理。
- プロバイダーページのメニューからプラグインを管理。トークンで非公開のスキルリポジトリにもアクセス可能。
- プロキシ設定で出口 IP を確認でき、ルーティングするプロバイダーごとに料金倍率を設定可能。
- Codex ルーティングの互換性、旧 OpenCode セッションの使用量取り込み、一部モデルの料金計算を修正。
- 一般設定で画面の表示密度とズームを調整できます。

## 更新方法

「このアプリについて」から更新を確認できます。Windows ポータブル版は新版の ZIP をダウンロードし、アプリを終了してファイルを置き換えてください。macOS 版はアドホック署名を使用しており、初回起動時にシステムの「プライバシーとセキュリティ」で許可が必要になる場合があります。
