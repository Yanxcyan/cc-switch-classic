# CC Switch Classic v4.0.26

Integrates upstream v4.0.23–v4.0.25 application updates while preserving the Classic interface, tab spacing, curated provider catalog and existing configuration compatibility.

## New and improved

- On-demand MCP connectivity checks for stdio, HTTP and SSE.
- Optional Codex official quota protection, disabled by default, can pause official requests sent through the local router before five-hour or weekly quotas run out. Sub-agent concurrency limits are also configurable.
- Automatic exchange rates for usage statistics; manual rates remain the default.
- Native configuration editors for Kimi, MiniMax and Oh My Pi, plus browser auto-open preferences and copyable login links.
- Improved reasoning-level compatibility, model descriptions and provider presets, plus Kimi session deletion.

## Fixes

- Reject browser-origin requests and unexpected hostnames at the local proxy to strengthen protection against browser requests and DNS rebinding.
- Fix duplicate Codex/Pi usage records, import issues and model pricing synchronization in proxy-only environments.
- Fix Windows form flicker, tray responsiveness during startup, lightweight mode and terminal inheritance of routing settings.
- Preserve historical preset positions and recognition of old endpoints so existing providers remain compatible with Classic's catalog and promotional-link policy.

## Updating

Existing Classic users can check for updates in About. For Windows portable builds, download the new ZIP, quit the app and replace the program files. First-time Classic users must install from this repository's Releases; upstream installations do not migrate automatically.

macOS builds use ad-hoc signing and are not notarized by Apple. First launch may require approval in System Settings → Privacy & Security.
