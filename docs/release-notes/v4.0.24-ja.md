# CC Switch Classic v4.0.24

CC Switch v4.0.22 をベースにした Classic 初の独立リリースです。

- クラシックな画面を復元し、v4 のモード、アカウント、プロキシ、使用統計を維持。
- 設定の全6タブを広いレイアウトに統一。プロジェクトと更新履歴のリンクを Classic リポジトリへ変更。
- 独立した製品名、アプリ識別子、更新署名を使用。更新元は `Yanxcyan/cc-switch-classic`。
- Windows x64/ARM64 のインストーラーとポータブル版、macOS ユニバーサル版、Linux x64/ARM64 を提供。
- プロバイダー一覧を PackyCode、公式サービス、Qiniu など主要プラットフォームに整理。保存済みの設定は引き続き編集・利用できます。
- 他のスポンサーの API キー取得用リンクを非表示にし、PackyCode を https://www.packyapi.ai/register?aff=VGGr に変更。

初回は本リポジトリの Releases から手動でインストールしてください。上流版の更新機能から Classic へは移行できません。以後は「情報」で Classic の更新を確認できます。Windows ポータブル版は終了後に新しい ZIP のプログラムへ置き換えます。

Apple Developer の証明書が未設定の場合、macOS 版は ad-hoc 署名を使用し、Apple の公証はありません。初回起動には「システム設定 → プライバシーとセキュリティ」で許可が必要な場合があります。

Classic は既存の `.cc-switch` データとクライアント設定を共有し、`ccswitch://` の互換性を維持します。インストール識別子の分離はデータの分離ではありません。事前に設定をバックアップし、両方の版を同時に実行しないでください。
